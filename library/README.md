# Level Up Academy: content library

Ready-to-print material made by Claude-as-me. Every paper passes the automatic checks before it is built: marks add up, every chemical equation is balanced (atoms counted), MCQ keys point at a real option, and correct answers are spread across (a)–(d).

> **Before using a test with students:** this repo is public, so answer keys here can be found online. Make the repo private (GitHub → Settings → Change visibility) or treat these as practice material.
