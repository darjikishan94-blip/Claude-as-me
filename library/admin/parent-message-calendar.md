# Parent message calendar: the whole academic year (April–March)

Every routine message Level Up Academy sends in a year, in Kishan's voice, ready to paste.
- Change only the `[brackets]`. Never guess a date, time or amount; check `me/academy.md` or ask.
- Verify each weekday before sending: `python3 -c "import datetime;print(datetime.date(2027,1,14).strftime('%A'))"`
- **9th Foundation group:** start with "Respected Parents," instead of "Hello Parents,", leave out emojis, and keep the "Kindly…" tone.
- **Fee messages** (all four quarterly rounds) use the `parent-fee-messages` skill. They are marked 💰 below but not duplicated here.
