# Tough conversations playbook

How Kishan handles difficult messages from parents, with replies ready to adapt. Use it with the **reply-as-me** skill.

**The pattern for every tough message:** thank → acknowledge (in their words) → facts → plan + time → offer a call.
- Never argue in text. If it's heated, send a calm holding reply and **call**.
- Never mention another child's marks, fees or behaviour.
- Never promise discounts, refunds, marks or schedule changes Kishan hasn't decided. Where a decision is needed, there are two versions: **If yes** and **If no**.
- `[Policy: …]` means Kishan has to fill it in once (and save it to `me/academy.md`).

---

## 1. "My child scored so low. What are you teaching?"
```
Hi! Thank you for telling me. I completely understand your concern 🙏
I went through [Name]'s paper: most marks were lost in [area, e.g. numericals / long answers]. [He/She] understands the concepts in class, so this is fixable.
Here's the plan: [extra practice sheet + re-test on date]. I'll update you after the re-test.
Can I call you this evening for 5 minutes?
```
*Notes:* lead with the specific cause, not a defence. Fill `[area]` only from the marked paper or the test-results analysis.

## 2. Request for a fee discount or instalments
**If yes:**
```
Hi! Thank you for being open with me 🙏 Yes, we can do that. [Arrangement: e.g. ₹[amount] on [date] and ₹[amount] on [date].]
I'll note it on my side. Please don't worry, and let's keep [Name]'s studies going as usual.
```
**If no:**
```
Hi! I understand, and thank you for telling me 🙏 I'm not able to change the fee itself, but I can [alternative: give a little more time / split it into two parts]. Would that help?
```
*Notes:* decide case by case. Once it's agreed, the fee messages for that family use the arrangement wording (see `parent-fee-messages`).

## 3. "We'll pay the fees a bit late this month"
```
Hi! No problem at all, thanks for letting me know 🙂 Please pay whenever you can by [date].
```
*Notes:* if no date was given, write "whenever it's convenient this month". Don't send reminders before that date.

## 4. Request to change batch timing
**If a seat is available:**
```
Hi! Sure 🙂 [Name] can join the [time] batch from [day, date]. I'll add [him/her] to that group.
```
**If not:**
```
Hi! I checked. The [time] batch is full right now 🙏 I'll keep [Name] first on the list and tell you as soon as a seat opens. Till then, the current batch continues as usual.
```

## 5. "My child says they don't understand the teaching"
```
Hi! Thank you for telling me. This is exactly the kind of thing I want to know 🙏
I'll sit with [Name] for a few minutes after class on [day] to see where exactly it's getting difficult. Sometimes it's one missing concept from earlier classes.
I'll update you after that. Please ask [him/her] to note down any doubts too.
```
*If the complaint is about another teacher:* thank them, say you'll look into it personally, and **call**. Don't discuss the teacher in text.

## 6. "Another coaching class / another student got more marks"
```
Hi! I understand you want the best for [Name], and so do I 🙂
Rather than comparing, let's look at [his/her] own progress: [first test marks] → [latest marks]. [Specific improvement or gap.]
The next goal is [specific, e.g. full marks in Section A]. I'll keep you updated.
```
*Notes:* never discuss another child's marks, even if the parent names them.

## 7. Raising a behaviour issue (Kishan starts the conversation)
```
Hi! Hope you're doing well 🙂 I wanted to share something small before it becomes a habit.
[Name] has been [specific behaviour, e.g. using the phone during class] for the last [few classes].
[He/She] is a bright student, so I'd really like [him/her] to make the most of the class. Could you have a gentle word at home? I'll keep an eye on it too.
```
*Notes:* one specific behaviour, no labels ("careless", "naughty"). Start and end with something positive.

## 8. "We want to stop classes" (mid-year withdrawal)
```
Hi! Thank you for letting me know 🙏 May I ask what made you decide? It really helps me improve.
[Policy: fees for the current [month/quarter] are … / refund rule …]
If there's anything I can change (timing, extra help), please do tell me. Either way, I wish [Name] all the best!
```
*Notes:* ask the reason once, gently, and never pressure. Refund wording follows the policy. If there is no policy yet, send the holding reply and decide.

## 9. Asking for extra classes free of cost
**If yes:**
```
Hi! Sure 🙂 [Name] can join the doubt-solving session on [day] at [time].
```
**If no:**
```
Hi! I understand 🙏 The extra sessions are [Policy: part of the special batch / paid at ₹…]. What I can do is [alternative: give [him/her] practice sheets / answer doubts after class on [day]].
```

## 10. Messages late at night
Reply the next morning:
```
Good morning! Sorry, I saw your message only now 🙂 [Answer.]
```
*Optional one-time group note (beginning of the year):*
```
Hello Parents, a small request: I reply to messages between [9 AM] and [8 PM]. For anything urgent, please call. Thank you for understanding 🙏
```

## 11. Child absent for many days without informing
```
Hi! Hope everything is okay at home 🙏 [Name] hasn't been in class since [date], so I just wanted to check in.
We've covered [topics] meanwhile. I'll share the notes so [he/she] can catch up.
Do let me know if there's anything I should be aware of.
```

## 12. A negative public review (Google / social media)
*A public reply should be short and calm, and move the conversation private. Never share student details.*
```
Thank you for your feedback. I'm sorry to hear about your experience, and I'd really like to understand and fix it. Please call or message me at [number] so we can talk. – Kishan, Level Up Academy
```
*Then call the parent. Never argue in public, and never reveal marks, fees or attendance.*

## 13. "What marks did [another child] get?"
```
Hi! I'm sorry, I share each child's marks only with their own parents 🙂 I hope you understand. But I'm happy to talk about how [Name] is doing compared with [his/her] last test!
```

## 14. "My child is very stressed about exams"
```
Hi! Thank you for telling me. This is really important 🙏
A little nervousness is normal, but let's not let it become too much. From my side, I'll [give a clear revision plan / keep tests low-pressure / talk to [him/her] after class].
At home, sleep, light food and some fun time help more than extra hours of studying. And please do tell [him/her] that marks are not everything 🙂
Can we talk on the phone tomorrow?
```
*If there is any sign of serious distress, call the parent the same day. Don't handle it only over text.*

## 15. "Please re-check my child's paper / marks"
```
Hi! Of course 🙂 Please send me a photo of the page, and I'll re-check it today.
```
*After re-checking:*
- *If there was a mistake:* `Hi! You're right, I missed [x] mark(s) in Q[n]. Updated score: [marks]/[max]. Sorry about that 🙏`
- *If the marks are correct:* `Hi! I re-checked it. In Q[n], the answer needed [missing point], which is why [x] mark(s) were cut. I'll show [Name] how to write it for full marks next time 🙂`

## 16. "But I already paid!" (disputed fee)
```
Hi! Thank you, let me check my records right away 🙏 Could you share the date and mode of payment (cash / UPI) and a screenshot if you have one?
```
*Then check the fee tracker. Never argue an amount from memory. If it was Kishan's error, apologise and confirm in writing.*
